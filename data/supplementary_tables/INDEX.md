In the manuscript they are cited as Repository Tables RT1 to RT12. The original table number is kept in the file name (`former S04` and so on) so earlier references can be traced.
The printed supplementary tables of the current manuscript are S1 to S13; the "Former number" column gives each repository table's number in the earlier draft it was moved from.
