As-run scripts for the gene-recognition audit (Supplementary Results S16, Supplementary Table S13). See
`data/derived/gene_recognition_audit/README.md` for what each output holds and which steps can be re-run. Scripts read and write next to
themselves (per-cancer files named `<cancer>_*.csv`); copy the scripts and the data folders into one work folder to run them.
Only the repository root is configurable (`ONCODIGGER_PAPER_REPO`).
